# idchug - Webブラウザ完結型・バンド特化DAW 🎸🥁⚡

思いついたバンドサウンドのアイデアを1分以内に形にするための、Webブラウザ完結型シーケンサーDAW。
アクセスした瞬間にバンド編成（Vo, Lead Gt, Rhythm Gt, Ba, Dr, Keys）がスタンバイされ、コード配置・ドラッグ＆ドロップ・鼻歌入力で爆速スケッチできます。

---

## 🌟 主な機能と特徴

1. **堅牢な先行スケジューラ (Lookahead Scheduler)**
   - Web Audio APIの正確なオーディオクロックと25msインターバルの先行スケジューリングにより、画面描画負荷やタブ切り替え時でも再生タイミングが揺れません。
   - 直近4打の平均間隔から即座にテンポを割り出す「タップテンポ（TAP）」機能搭載。

2. **グローバルコードトラック ＆ バンド伴奏自動追従**
   - 最上部の小節グリッドにコードネーム（例: `Am`, `F`, `C`, `G`, `E5`, `F#m` など）を入力するだけで、全パートが自動追従。
   - **Rhythm Gt (Chug):** `WaveShaperNode` によるハイゲインディストーションとLPF制御により、重厚なパワーコードと切れ味鋭いブリッジミュート（P.M. / Chug）を再現。
   - **Bass:** コードのルート音を自動認識し、8分音符でタイトに刻むベースラインを生成。
   - **Keys:** 美しいパッド/エレピ和音で全体のサウンドをサポート。

3. **ドラムのハイブリッド方式（パターンDnD ＋ 16ステップ編集）**
   - 画面下のパレットから「8-Beat Basic」「8-Beat Drive」「Punk / Fast Chug」「Fill-In」などのプリセットブロックを小節へドラッグ＆ドロップ配置。
   - 配置されたブロックをダブルクリックすると「16ステップ・ドラムエディタ」が開き、Kick / Snare / HiHat (C/O) / Toms / Crash を自由にインプレイス編集・ユニーク化可能。

4. **鼻歌入力（Audio-to-MIDI）**
   - マイクに向かってハミング（鼻歌）を歌うだけで、自己相関（Autocorrelation）アルゴリズムによりリアルタイムにピッチ検出。
   - テンポ（BPM）に合わせて16分音符グリッドに自動クオンタイズし、MIDIノートとしてLead GtやVocalトラックへ一発挿入。
   - プラガブル設計（`AudioToMidiService`）により、将来のPython AIバックエンド連携も容易。

5. **プロジェクト入出力（`.idchug`）**
   - 楽曲データを単一の `.idchug` (JSON) ファイルとして保存・ダウンロード。
   - ファイル選択からの読み込み、および画面全体へのファイルドラッグ＆ドロップによる瞬時復元に対応。

## 🚀 起動・開発コマンド

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動
npm run dev

# プロダクションビルド
npm run build
```
